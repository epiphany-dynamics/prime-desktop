# Code of Conduct

## Be decent

- Be respectful
- Assume good intent
- No harassment, hate, or personal attacks
- No spam, scams, or crypto/drive-by promo

## Technical spaces

- Do not post secrets, API keys, or private data
- Keep criticism about the work, not the person
- Voice features are out of scope; please do not push them as parity requirements

## Report problems

Email **hello@epiphanydynamics.ai** or use a private security report for safety issues
([SECURITY.md](SECURITY.md)).

## Enforcement

Epiphany Dynamics maintainers may warn, edit, or ban accounts that break this policy.
